# Hospital-dataset
A dataset containing hospital-related information for data analysis , visualization and learning purposes
Hospital Patient Dataset

Project Overview

This repository contains a hospital patient dataset that stores basic patient details, health problems, consulting doctor information, and physical health measurements.

Dataset Information

The dataset includes the following columns:

Name – Patient's name.

Problem – Health problem or medical condition reported by the patient.

Consulting Doctor – Name of the doctor consulting the patient.

Weight – Patient's weight in kilograms (kg).

Height – Patient's height in centimeters (cm).

Temperature – Patient's body temperature in degrees Celsius (°C).

Project Objectives

Organize hospital patient information.

Understand patient health details.

Analyze weight, height, and temperature records.

Identify common health problems.

Practice data analysis and visualization.

Tools Used

Microsoft Excel

Python

Pandas

Matplotlib

Purpose

This dataset is created for educational purposes and to practice basic data management, analysis, and visualization.

Privacy Notice

Use fictional or anonymized patient information. Do not publish real patient names or confidential medical details.
